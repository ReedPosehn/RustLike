# RustLike

A top-down roguelike prototype built in Rust using the Bevy engine.  
Features procedural seeded dungeons, AABB tile-based movement with wall sliding, Bevy-managed state transitions, and a growing gameplay loop. Designed as a sandbox for experimenting with ECS game design.

## Getting Started

```bash
# Clone
git clone https://github.com/ReedPosehn/RustLike.git
cd RustLike

# Generate assets (requires Pillow)
pip install pillow
python generate_assets.py

# Build and run
cargo run

# Run tests
cargo test
```

Assets are under `assets/` and generated by `generate_assets.py`. To replay a specific dungeon layout, copy the seed printed to the console at startup and set `FIXED_SEED = Some(your_seed)` in `src/main.rs`.

## Source Layout

```
src/
├── main.rs    # constants, DungeonSeed resource, app entry, setup
├── map.rs     # TileKind, Tilemap, map builders, tile spawning, tests
├── player.rs  # Player component, AABB movement & collision
└── state.rs   # MapState (Bevy States), World resource, transition systems
```

## Features

- Procedural dungeon generation with random rooms and L-shaped corridors
- Seed-based generation — reproducible layouts, seed printed at startup
- AABB player movement with wall sliding (WASD / arrow keys)
- Hub ↔ dungeon transitions via Bevy `OnEnter`/`OnExit` state schedules
- Dungeon sized to fit the 1280×720 window — always fully visible
- Pixel-art sprites for player classes (warrior, mage, paladin, rogue) and enemies (goblin, orc, skeleton, spider)
- 14 automated tests covering coordinate helpers and dungeon generation invariants

## Roadmap

### ✅ Phase 1 – Prototype
- Project setup, tilemap system, procedural dungeon, player movement, state transitions

### ✅ Phase 2 – Movement & Collision
- AABB collision with wall sliding, independent X/Y axis resolution, sprite hitbox aligned to canvas

### ✅ Phase 3 – Architecture & Developer Experience
- Modular codebase (`map.rs`, `player.rs`, `state.rs`)
- Bevy `States` API with `OnEnter`/`OnExit` schedules
- Seed-based dungeon generation
- Dungeon sized to fit screen
- Automated test suite (14 tests)

### ⚔️ Phase 4 – Enemies & Combat (next)
- Enemy spawning in dungeon rooms (sprites already in assets)
- Simple AI: random walk or player-chase
- Melee combat: health, damage, death
- Multiple player classes

### 🎮 Phase 5 – Gameplay Mechanics
- Inventory and item pickup
- Procedural level features: keys/locks, themed rooms
- Dungeon depth and difficulty scaling

### ✨ Phase 6 – Polish & UI
- HUD: health bar, inventory, message log
- Sound effects and music
- Save/load system
- Walk cycle, idle, and attack animations
- Permadeath and roguelike meta-progression
