# RustLike

A top-down roguelike prototype built in Rust using the Bevy engine.
Features procedural seeded dungeons, AABB movement with wall sliding, real-time enemy AI, and Bevy-managed state transitions.

## Getting Started

```bash
# Clone
git clone https://github.com/ReedPosehn/RustLike.git
cd RustLike

# Generate assets (requires Pillow)
pip install pillow
python generate_assets.py

# Build and run
cargo run

# Run tests
cargo test
```

Assets are under `assets/` and generated by `generate_assets.py`. To replay a specific dungeon, copy the seed printed to the console at startup and set `FIXED_SEED = Some(your_seed)` in `src/main.rs`.

## Source Layout

```
src/
├── main.rs      # constants, DungeonSeed resource, app entry, setup
├── map.rs       # TileKind, Tilemap, map builders, tile spawning, tests
├── player.rs    # Player component, AABB movement & collision
├── state.rs     # MapState (Bevy States), World resource, transition systems
└── enemies.rs   # EnemyKind, Enemy, EnemyAi, spawn/despawn/AI systems
```

## Features

- Procedural dungeon generation with random rooms and L-shaped corridors
- Seed-based generation — reproducible layouts, seed printed at startup
- AABB player movement with wall sliding (WASD / arrow keys)
- Hub ↔ dungeon transitions via Bevy `OnEnter`/`OnExit` state schedules
- Dungeon sized to fit the 1280×720 window — always fully visible
- Enemies (goblin, orc, skeleton) that wander and chase the player
- Real-time wander/chase AI with wall-aware collision
- Pixel-art sprites for player classes and enemies
- 14 automated tests covering coordinate helpers and dungeon generation

## Controls

| Key | Action |
|---|---|
| WASD / Arrow keys | Move player |
| Walk onto stairs | Enter / exit dungeon |
