# RustLike Project Status

## 🚧 Current Context

- **Language & Framework:** Rust + [Bevy 0.11](https://bevyengine.org/)
- **Workspace:** Seven modules in `src/` — `main.rs`, `map.rs`, `player.rs`, `state.rs`, `enemies.rs`, `combat.rs`, `hud.rs`. Dependencies: `bevy`, `rand`.
- **Assets:** 32×32 PNG sprites generated by `generate_assets.py` (Pillow).
- **Vision:** Top-down roguelike with smooth movement, procedural dungeons, real-time enemy AI, and a growing combat loop.

## ✅ Features Implemented

1. **Tilemap & Dungeon** — Seed-based procedural rooms, L-shaped corridors, stairs. Fits 1280×720.
2. **AABB Movement & Collision** — WASD/arrows; wall sliding; independent X/Y axes.
3. **State Transitions** — Bevy `States` with `OnEnter`/`OnExit` for map/enemy lifecycle.
4. **Enemy Spawning** — Goblins, orcs, skeletons (1–2 per room, last room reserved for stairs).
5. **Enemy AI** — Wander (pause/walk) + chase state machine. Wall-aware AABB collision. Hysteresis radii (5 tile chase, 7 tile lose).
6. **Combat Foundation** — `DamageEvent { target, amount, source }` — all damage flows through one event. Extensible `DamageSource` enum.
7. **Player Melee** — `F` key attacks in the `Facing` direction (updated from movement keys). Hits enemies within one tile.
8. **Enemy Contact Damage** — 10 HP/tick on 0.8s timer when enemy AABB overlaps player.
9. **Health System** — `Health { current, max }` on player (100 HP) and enemies (Goblin 30, Orc 60, Skeleton 45). `Dead` marker triggers despawn.
10. **HUD** — Rounded dark panel, 2px white border, gradient fill (green→yellow→red). Built in memory via `Assets<Image>` — no async loading issues.
11. **Enemy Health Bars** — World-space green sprites above each enemy; shrink to show remaining HP.
12. **Damage Splats** — Yellow floating `-N` text that rises and fades at hit positions.
13. **Automated Tests** — 14 tests in `map.rs` covering coordinates, dungeon invariants, determinism.

## 📌 Current Known Issues

- No player death screen — `Dead` marker added but no game-over state/UI.
- No ranged or magic attacks — `DamageSource` has variants but no systems.
- Enemies don't pathfind — can get stuck on wall corners when chasing.
- Enemies can overlap each other (no separation).
- Dungeon dimensions must be recalculated manually if `SCALE` changes.
